# Imagify AI 🎨

Imagify AI is a full-stack web application that allows users to generate unique images from text prompts using the power of AI. Users can register, log in, and manage their credits to create stunning visuals on demand. The application is built with the MERN stack and leverages the ClipDrop API for image generation.

-----

## \#\# Key Features ✨

  * **User Authentication**: Secure user registration and login system using JWT (JSON Web Tokens) for session management.
  * **AI Image Generation**: Enter a text prompt to generate high-quality images through the ClipDrop API.
  * **Credit System**: Each registered user receives a starting credit balance. One credit is deducted for each image generated.
  * **Responsive Design**: A clean and modern user interface that works seamlessly on both desktop and mobile devices.
  * **Full-Stack Architecture**: Built with a React frontend and a Node.js/Express backend, ensuring a robust and scalable application.

-----

## \#\# Technologies Used 🛠️

This project is built using the MERN stack and other modern web technologies:

  * **Frontend**: React, Axios, Tailwind CSS
  * **Backend**: Node.js, Express.js
  * **Database**: MongoDB (with Mongoose)
  * **Authentication**: JWT (JSON Web Tokens), bcrypt
  * **AI Service**: ClipDrop API
